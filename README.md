# LastMusic

Вебзастосунок для прослуховування музики, перегляду статистики Last.fm і скроблінгу відтворених треків. Інтерфейс українською мовою; для роботи не потрібні збірка, Node.js або бекенд-сервер.

**Демо:** [drbryanman.github.io/LastMusic](https://drbryanman.github.io/LastMusic/)

## Можливості

- Відтворення пісень і відео з YouTube Music із чергою, пошуком, перемотуванням, регулюванням гучності та мініплеєром.
- Інтеграція з Last.fm: останні скробли, статистика, популярні треки/виконавці/альбоми й рекомендації.
- Скроблінг відтворення та оновлення статусу «Зараз грає» після авторизації Last.fm.
- Перегляд улюблених треків, бібліотеки та сторінок виконавців; пошук і фільтри періоду.
- Радіопотоки на основі бібліотеки, міксу або рекомендацій.
- Експорт та імпорт налаштувань у JSON.
- Адаптивний інтерфейс для комп’ютерів і мобільних пристроїв.

## Запуск

### Онлайн

Відкрийте [демо](https://drbryanman.github.io/LastMusic/). Для роботи з вашим профілем Last.fm потрібно ввести налаштування у застосунку.

### Локально

1. Завантажте або клонуйте репозиторій.
2. У корені проєкту запустіть будь-який локальний статичний HTTP-сервер, наприклад:

   ```bash
   python -m http.server 8000
   ```

3. Відкрийте [http://localhost:8000](http://localhost:8000) у браузері.

Застосунок використовує JavaScript ES-модулі, тому відкривати `index.html` напряму через `file://` не рекомендується. Зовнішній бекенд для базового запуску не потрібен.

## Налаштування Last.fm

1. Створіть API-застосунок на [сторінці Last.fm API](https://www.last.fm/api/account/create) і отримайте **API key** та **Shared secret**.
2. У LastMusic відкрийте **Налаштування** та вкажіть ім’я користувача Last.fm, API key і Shared secret.
3. Натисніть **Авторизувати**, надайте застосунку доступ на Last.fm, поверніться до LastMusic і натисніть **Завершити**.
4. Збережіть налаштування. Після авторизації можна переглядати персональні дані та скроблити відтворені треки.

Приклад конфігурації наведено у [`config.example.json`](config.example.json). Застосунок зберігає налаштування у `localStorage` цього браузера. Файл `config.json` можна використовувати локально як початкове джерело конфігурації, але не публікуйте його: він може містити секрети та ключ сесії. `config.json` доданий до `.gitignore`.

## Технології та зовнішні сервіси

- HTML, CSS і нативний JavaScript (ES-модулі); залежностей для встановлення немає.
- Дані профілю та скроблінг — [Last.fm API](https://www.last.fm/api).
- Пошук і відтворення медіа — YouTube Music, YouTube IFrame Player API та публічні інстанси Piped.

Для використання потрібне підключення до інтернету. Доступність пошуку та відтворення залежить від сторонніх сервісів, регіону й авторських обмежень.

## Структура проєкту

```text
.
├── index.html             # Основна сторінка застосунку
├── artist.html            # Перенаправлення на сторінку виконавця в SPA
├── library.html           # Перенаправлення на бібліотеку в SPA
├── loved.html             # Перенаправлення на улюблені треки в SPA
├── config.example.json    # Шаблон локальної конфігурації
├── css/                   # Стилі інтерфейсу
└── js/                    # Last.fm API, плеєр, маршрутизація та сторінки
```

## Безпека та приватність

Ключі Last.fm, секрет і ключ сесії зберігаються у браузері користувача. Не передавайте експортований файл конфігурації іншим людям і не додавайте реальні облікові дані до репозиторію. Використовуйте застосунок лише з довіреного розміщення та пам’ятайте, що запити до Last.fm і сервісів відтворення обробляються цими сторонніми сервісами.
