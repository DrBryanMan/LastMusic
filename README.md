# 🎵 Scrobble Deck

> Сучасний автономний вебінтерфейс для прослуховування музики через **YouTube** та синхронізації з **Last.fm** у стилі Windows 11 Fluent Design (Acrylic).

---

## ✨ Особливості

- **Повний Serverless режим**: Працює без жодного бекенд-сервера або залежностей. Можна запускати подвійним кліком по `index.html` або хостити на **GitHub Pages**.
- **Безперервне відтворення (SPA)**: Перехід між розділами («Головна», «Улюблені», «Бібліотека», «Виконавець») не перериває відтворення музики. При переході з головної сторінки автоматично з'являється плаваючий міні-плеєр.
- **YouTube Music Player**: Автоматичний пошук відео через YouTube Data API v3 та плавне керування чергою.
- **Повна підтримка Last.fm**:
  - Автоматичний скроблінг треків та оновлення статусу «Зараз грає».
  - Додавання та видалення з «Улюблених» (`track.love` / `track.unlove`) в один клік.
  - Картка «Зараз грає» зі статистикою прослуховувань треку та артиста.
- **Повноцінна Бібліотека**:
  - 4 вкладки: **Всі скроблі** (повна історія), **Виконавці**, **Альбоми**, **Треки**.
  - Справжня пагінація Last.fm без обмежень (на десятки тисяч треків/виконавців).
  - Перемикач режимів перегляду: **Список** або **Сітка** (`[ ≡ ] [ ⊞ ]`).
  - Глобальний пошук через Last.fm Search API.
  - Спадні списки періодів (7 днів, місяць, 3/6 місяців, рік, увесь час) у стилі Acrylic Dropdown.
- **Нескінченні радіопотоки**: Швидкий запуск потоку з вашої бібліотеки, персонального міксу або рекомендацій.
- **Персональна сторінка артиста**: Біографія, топ-треки, топ-альбоми, схожі виконавці та ваша особиста статистика.
- **Безпека**: Усі ключі доступу та сесійний ключ зберігаються виключно локально у вашому браузері (`localStorage`). Є функції експорту та імпорту налаштувань.

## 🚀 Швидкий старт

### Варіант 1: Запуск подвійним кліком (Офлайн / Standalone)
Просто відкрийте файл `index.html` або `ScrobbleDeck-Standalone.html` у будь-якому сучасному веб-браузері (Chrome, Edge, Firefox, Brave).

### Варіант 2: GitHub Pages (Хмарний хостинг)
1. Увімкніть **GitHub Pages** у налаштуваннях репозиторію (`Settings -> Pages -> Deploy from a branch -> main / (root)`).
2. Відкрийте ваше персональне посилання в браузері.

### Варіант 3: Локальний Python-сервер (Опціонально)
Якщо ви віддаєте перевагу локальному серверу:
```bash
python server.py
```
Відкрийте [http://localhost:9000](http://localhost:9000).

## ⚙️ Налаштування

При першому відкритті натисніть іконку шестірні ⚙️ або плашку статусу скроблінгу:
1. **Користувач Last.fm**: ваш логін на Last.fm.
2. **Last.fm API Key & Secret**: безкоштовно створюються на [last.fm/api/account/create](https://www.last.fm/api/account/create).
3. Натисніть **«Авторизувати»**, підтвердіть доступ на сторінці Last.fm, поверніться і натисніть **«Завершити»**.
4. **YouTube Data API Key**: отримайте безкоштовний ключ у [Google Cloud Console](https://console.cloud.google.com/) (увімкніть YouTube Data API v3).
